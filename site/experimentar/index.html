Android

Aplicação nativa · APK

Disponível

A app Android completa, num ficheiro APK assinado. Ainda não está na Google Play: o download é feito a partir das versões publicadas do projeto no GitHub.

Descarregar para Android
Como instalar
  1. Descarrega o APK no telemóvel e abre-o a partir das transferências.
  2. O Android pede autorização para instalar apps dessa origem (o browser ou a app de ficheiros). Autoriza, instala e abre o Miven.
  3. Entra com a tua conta ou cria uma.
  4. Para atualizar, descarrega o APK outra vez e instala por cima: os dados da conta continuam.

Recomendado para este aparelho

iPhone

Aplicação nativa · SideStore

Disponível

A app iOS instala-se pelo SideStore. Não é distribuída pela App Store: o ficheiro (IPA) não vem assinado pela Apple, e o SideStore assina-o no teu iPhone com o teu Apple ID.

  • iOS 16.4 ou mais recente
  • Com um Apple ID gratuito, a assinatura dura 7 dias; o SideStore renova-a quando o abres
Instalar no iPhone

Recomendado para este aparelho

Instalar no iPhone pelo SideStore

  1. Instala o SideStore no iPhone, se ainda não o tiveres, seguindo o guia oficial em sidestore.io.
  2. Adiciona a fonte do Miven. No SideStore, abre Sources, toca em + e cola este endereço:
    https://raw.githubusercontent.com/CentFlowLab/CentFlow/master/sideload/source.json

  3. Instala o Miven a partir da fonte e abre a app.
  4. Entra com a tua conta ou cria uma.

Quando sair uma versão nova, o SideStore mostra o botão de atualizar e pede confirmação. A atualização instala-se por cima e mantém os dados.

Precisas de ajuda?

Consulta o suporte ou escreve para mivenapp@gmail.com. Podes sempre começar pela aplicação web, sem instalar nada.
