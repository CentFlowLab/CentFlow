# Palavras-chave — CentFlow (App Store)

**Limite Apple:** 100 caracteres, separadas por vírgula, sem espaços após vírgulas.

## String sugerida (PT)

```
finanças,orçamento,despesas,património,poupança,créditos,talões,OCR,banco,pessoal
```

**Caracteres:** 82

## Palavras individuais (referência)

| Palavra | Justificação na app |
|---------|---------------------|
| finanças | Categoria e propósito principal |
| orçamento | Gasto disponível mensal, orçamentos por categoria |
| despesas | Movimentos, análise de gastos |
| património | Património líquido, aba Análises |
| poupança | Objectivos de poupança (Ativos) |
| créditos | Aba Créditos, passivos |
| talões | OCR de recibos |
| OCR | Digitalização de talões |
| banco | Open Banking (GoCardless) |
| pessoal | Gestão financeira pessoal (não empresarial) |

## Play Store

A Play Store não usa campo de keywords separado; integrar termos na descrição curta e completa.

## Evitar

- Termos de investimento regulado («consultoria», «trading») — a app não presta esse serviço.
- Nomes de concorrentes.
- Keywords irrelevantes (empréstimos comerciais, crypto trading).
